# Ahmed Mahmood — Silk Waves Portfolio

موقع جديد مستقل عن كل نسخ البورتفوليو السابقة، مطابق من حيث التوزيع والهوية إلى التصميم المختار مع Waves حقيقية متحركة بزاوية قريبة من 45 درجة، وأرقام 0/1 متحركة بهدوء، وطبقات تضمن وضوح الكتابة.

## التشغيل

افتح `index.html` مباشرة بمتصفح Chrome أو Edge. الموقع HTML/CSS/JS بدون npm أو خادم. أو شغله من VS Code باستخدام Live Server.

## الصور الأصلية (مهم قبل النشر)

الصورة الشخصية الأصلية ولقطة PrivacyGuard مأخوذ مسار كل منهما من البورتفوليو الأصلي العام، والموقع يحاول تحميلهما مباشرة من GitHub إلى أن تحفظ نسخة محلية. **لتثبيت الصور قبل النشر** افتح PowerShell في مجلد الموقع وشغّل:

```powershell
powershell -ExecutionPolicy Bypass -File .\download-original-assets.ps1
```

سيضع السكربت `assets/portrait.png` و`assets/privacyguard-dashboard.png` بالمجلد وسيعتمد الموقع عليهما تلقائياً. إذا أردت بورتريه بدون خلفية 100%، ضع صورتك الحقيقية المفرّغة بخلفية شفافة باسم `assets/portrait.png` (PNG مع alpha). CSS يموّه الحافة السفلية ولكنه لا يزيل خلفية صورة غير شفافة آلياً. لا تستخدم صورة الشخصية الموجودة بالتصميم المولّد؛ فهي ليست صورتك الحقيقية.

صورة Pet Rescue موضوعة كـ **CONCEPT ART** وليست صورة من اللعبة الفعلية، حتى لا توحي بأن اللعبة بلغت مرحلة لم تصل إليها. 8 صور Skate Run الحقيقية مضمنة في معرض المشروع.

## رفع GitHub Pages

1. فك الضغط، وشغّل سكربت الصور الأصليتين في جهازك وتأكد من النتيجة.
2. ارفع جميع الملفات إلى المستودع الذي تختاره، داخل المجلد الرئيسي للمستودع.
3. من GitHub: Settings → Pages → Deploy from a branch → main / (root) → Save.
4. تجنب رفع المشروع على مستودع قديم إلا بعد أخذ نسخة احتياطية وفحصه.

الروابط العامة الأخرى والمشاريع المستخرجة من البورتفوليو الأصلي مبينة داخل الموقع. الملفات لا تحتوي على مفاتيح API أو build steps. استخدمت ألواناً كحلية وبنفسجية متحفظة وسرعة حركة منخفضة، مع `prefers-reduced-motion` لتخفيف الحركة.
